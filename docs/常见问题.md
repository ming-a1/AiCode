# 常见问题

## 我的数据库文件会被上传吗？

不会。所有解析、浏览、编辑与导出都在浏览器本地完成（SQL 引擎跑在 WebAssembly 里），页面不上传数据库文件。「最近打开」的缓存存在本机浏览器 IndexedDB 中，可点「清空列表」删除。

## 支持哪些文件格式？

SQLite 系列：`.db` `.sqlite` `.sqlite3` `.db3` `.s3db` `.sdb` `.sqlite2`。加密（SQLCipher）数据库不支持。

## 为什么页面一开始显示「正在加载 SQL 引擎…」？

SQL 引擎（约 1MB）在首次加载时初始化，网络较慢时需要多等几秒；引擎数据已随页面内嵌，不依赖外部 CDN。

## 编辑后如何真正保存到文件？

页面内的修改只作用于内存副本。点工具栏「保存数据库」会下载一个修改后的 `.db` 文件，用它**替换磁盘上的原文件**即完成保存。不保存直接关闭会丢失修改（会有警告提示）。

## 「最近打开」会在多设备间同步吗？

不会，它只存在当前设备的当前浏览器里，纯本地缓存。

## 页面在手机上能用吗？

可以。窄屏下侧栏改为浮层（点工具栏列表按钮呼出），工具栏与表格会横向滚动。

## 导出的 CSV / TXT 里有 HTML 标签怎么办？

导出弹窗里勾选「去除 HTML 标签，导出为纯文本」；需要更精细的清洗可用下方的自定义正则替换。

## 用 GitHub Pages 部署的版本和仓库代码是什么关系？

仓库根目录的 `index.html` + `css/` + `js/` 就是完整应用，推送到 `main` 后 GitHub Pages 自动重建发布，见 [https://ming-a1.github.io/AiCode/](https://ming-a1.github.io/AiCode/)。
