# 使用指南

## 打开数据库

1. 打开 [在线页面](https://ming-a1.github.io/AiCode/)，等待拖放区从「正在加载 SQL 引擎…」变为「拖入数据库文件，或点击选择」
2. 点击中央拖放区选择文件，或直接把数据库文件拖进页面
3. 加载完成后进入工作区：左侧是数据表 / 视图列表，右侧是数据表格

也可以从「最近打开」列表中点击之前加载过的数据库（缓存在本机浏览器，不上传）。

## 浏览数据

- **切换表**：点左侧栏的表名或视图名；窄屏 / 手机上点工具栏的列表按钮呼出侧栏
- **筛选**：工具栏搜索框输入关键字，对当前表做模糊匹配
- **翻页**：底部选择每页行数（20 / 50 / 100 / 200），用「上一页 / 下一页」翻动
- **行详情**：点某一行，右侧弹出抽屉显示该行所有字段
- **选中字段**：点抽屉里或表格中的单元格即可选中，后续导出可精确到字段

## 编辑数据

> 所有修改先作用于页面内存中的数据库副本，点「保存数据库」导出后才真正生效；不保存直接关闭 = 放弃修改。

- **改单元格**：双击表格中的单元格进入编辑（单击只是选中字段）
- **新增行**：点「＋ 新增行」，在表末尾追加一行默认值 / 空值
- **删除行**：选中行后点「删除行」或抽屉里的「删除此行」，需二次确认
- **保存**：出现修改后工具栏会显示「保存数据库」，点击导出修改后的 `.db` 文件，用它替换原文件即完成保存

## 关闭数据库

点右上角「关闭」，若存在未保存修改会弹出警告。关闭只清空浏览状态（选中行、筛选、排序），不影响磁盘上的文件。
