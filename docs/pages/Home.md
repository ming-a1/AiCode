# DB Reader · SQLite 数据库查看器

一个**纯前端**的 SQLite 数据库网页查看器：不用安装任何软件，浏览器里打开 `.db` 文件即可浏览表结构、数据与视图，并支持编辑与多种格式导出。

- 在线地址：[https://ming-a1.github.io/AiCode/](https://ming-a1.github.io/AiCode/)
- 当前版本：**v1.4.1**
- 技术栈：原生 HTML / CSS / JavaScript + sql.js（WebAssembly 版 SQLite）

## 核心特性

- **本地处理**：SQL 解析、浏览、编辑、导出全部在浏览器内完成，数据不会上传到任何服务器
- **打开数据库**：点击选择或直接拖入 `.db` / `.sqlite` / `.sqlite3` / `.db3` / `.s3db` / `.sdb` 等 SQLite 文件
- **结构浏览**：左侧栏列出全部数据表与视图，切换即看
- **数据表格**：分页（20/50/100/200 行每页）、模糊筛选、点击行查看详情抽屉、点击单元格选中字段
- **编辑能力**：单元格改值、末尾新增行、删除行（二次确认），改完「保存数据库」导出新的 `.db` 文件
- **导出**：支持整个数据库 / 当前表 / 当前行 / 当前字段四个范围，可导出为 `.txt` `.json` `.csv` `.sql` `.md` `.db`
- **导出过滤**：去 HTML 标签转纯文本、自定义正则替换、按列勾选、按行范围截取
- **最近打开**：打开过的数据库缓存在本机浏览器（IndexedDB），随时重新加载

## 隐私说明

所有数据仅存在于你自己的浏览器中。页面不上传数据库文件，也不发起任何数据同步请求；「最近打开」列表与缓存存放在本机浏览器的 IndexedDB 中，可随时一键清空。
