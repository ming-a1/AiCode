# 导出功能

点工具栏「导出」打开导出弹窗，依次选择**范围 → 字段 / 行 → 格式 → 过滤**，右侧（下方）可实时预览，确认后点「导出下载」。

## 导出范围

| 范围 | 说明 |
|---|---|
| 整个数据库 | 全部表与视图 |
| 当前表 | 当前表 / 视图的全部行 |
| 当前行 | 当前选中的一行 |
| 当前字段 | 当前选中的一个字段 |

## 导出格式

| 格式 | 说明 |
|---|---|
| `.txt` | 纯文本，可选「每行独立成段」与自定义标题 |
| `.json` | 结构化 JSON |
| `.csv` | 表格 CSV，可直接用 Excel 打开 |
| `.sql` | 生成 `INSERT` 语句，可用于重建数据 |
| `.md` | Markdown 表格 |
| `.db` | 原始数据库文件副本（仅「整个数据库」范围可用） |

## 字段与行控制

- **导出字段**：勾选需要的列（✓ = 导出），支持全选 / 全不选
- **导出行范围**：指定起止行号，`0 - 0` 表示全部行
- **自定义标题**（`.txt`）：按行填写标题，插在每段内容上方，留空不加；需勾选「每行独立成段」

## 导出过滤（仅 txt / csv / md 生效）

- **去除 HTML 标签**：把 `<p>` `<br>` 等转为换行，并解码常见实体，导出纯文本
- **自定义正则替换**：输入正则与替换内容（支持 `$1` 引用，留空 = 删除匹配部分）

## 其它

- **文件名**：可自定义，留空用默认名，点「默认」恢复
- **复制完整内容**：把预览对应的完整导出文本复制到剪贴板（不受预览折叠限制）
